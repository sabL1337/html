Structuur van Linux

Alles begint bij de root directory /. Dit zijn de belangrijkste mappen:

MapWaar is het voor
/homeGebruikers
/etcSysteem files (configuratie)
/varVariabele files en logs
/binSysteem commando's
Alle mappen van de FHS (Filesystem Hierarchy Standard)
/binEssential user command binaries
/bootStatic files of the boot loader
/devDevice files
/etcHost-specific system configuration
/homeUser home directories
/libEssential shared libraries and kernel modules
/mediaMount point for removable media
/mntMount point for temporarily mounted filesystems
/optAdd-on application software packages
/sbinSystem binaries
/srvData for services provided by this system
/tmpTemporary files
/usr(Multi-)user utilities and applications
/varVariable files
/rootHome directory for the root user
/procVirtual filesystem documenting kernel and process status

Navigeren

pwd

Print Working Directory: laat zien in welke map je nu zit.

$ pwd

ls

List: laat de inhoud van een map zien.

$ ls
$ ls -l     # uitgebreide lijst
$ ls -a     # ook verborgen bestanden

cd

Change Directory: ga naar een andere map.

$ cd /var/log   # naar een map met pad
$ cd ..         # een map omhoog

man

Manual: laat de handleiding van een commando zien.

$ man ls

tree

Laat mappen en bestanden zien als een boomstructuur.

$ tree

Bestanden en mappen beheren

touch

Maak een lege file.

$ touch bestand.txt

mkdir

Maak een nieuwe map.

$ mkdir nieuwe_map

rm

Verwijder een bestand of map.

$ rm bestand.txt
$ rm -r nieuwe_map   # map verwijderen

cp

Kopieer een bestand of map.

$ cp bestand.txt kopie.txt

mv

Verplaats een bestand of map (werkt ook om te hernoemen).

$ mv bestand.txt nieuwe_map/

Bestanden lezen en bewerken

nano

Command line tekst editor.

$ nano bestand.txt

cat

Concatenate: laat de inhoud zien.

$ cat bestand.txt

less

Laat de inhoud zien van 1 pagina per keer.

$ less bestand.txt

head

Laat de inhoud zien van de bovenkant van een file.

$ head bestand.txt

tail

Laat de inhoud zien van de onderkant van een file.

$ tail bestand.txt

Tips

Commando's combineren

Met && voer je meerdere commando's na elkaar uit.

$ cd /etc && ls

Tab-toets

Druk op Tab om een commando of bestandsnaam automatisch aan te vullen.
